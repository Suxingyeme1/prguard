## PrettyTable controlled repair

The exact defective source-only Patch at Base Commit
`3c80d392d32f48b0ab1e368793ddb751dbe41807` was reviewed again in a new independent context. The
Reviewer reproduced the P2 interaction: `max_row_width` survives `</table>`, so the corrected
padding loop gives a later, narrower table an extra empty column.

Only the structured finding was forwarded to the Implementer. In one allowed repair round it
submitted two exact structured edits:

- reset `max_row_width` after generating each table;
- retain exact empty-cell padding and add short-row plus multi-table regression tests.

PRGuard produced the full replacement Patch with SHA-256
`66d64c44a621d4c92cdd441bc8161fe32cdaf79ddda73877417dfb7323e8055a`. The composed run used
297,398 input / 16,858 output / 265,856 cached tokens and completed in 301.252 seconds. Its final
targeted Harness gate passed 23 tests with no policy violations. The recursive repair Manifest
payload hash is
`1fe705d1b4fe1c5398b46e3e25dcd1c1884d64ebd9208e5c0e82b997d5536ff6`.

The composed gate was followed by a separate evaluator-owned Harness run rather than relying on
the Agent's claim. It applied the same Patch at the frozen Base Commit, passed all **340** tests,
then automatically reran the changed test module with **23 passed**. Its recursive Manifest payload
hash is `185c8662c84e000c8114813cfa8fc2e292beb4d07783fd958e3efcca9b362cdf`.

## Boundary and next priority

This is a strong end-to-end engineering case, not proof of universal Reviewer recall or repair
correctness. The same public Issue disclosed the initial off-by-one cause; the incremental evidence
is the independently found cross-table interaction and its Base/Candidate reproduction.

The next product increment should propose `review-routing-v2` as a new immutable policy version and
replay it over these frozen cases. The key design question is how to make stateful parser changes
review-required without routing every small, well-covered Patch. Additional manually checked
real-repository cases are required before selective routing can become a default.
