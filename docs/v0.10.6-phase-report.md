# v0.10.6 phase report: real Pull Request controlled repair

Status: implemented 2026-09-03.

## Objective

Close Demo B on the frozen defective Click #3199 Patch: replay the independently produced
source-linked finding, permit exactly one Implementer repair, then require both a fresh deterministic
gate and an Agent-invisible behavior check.

## Information boundary

The repair Implementer received only:

- the original Issue and exact candidate Patch;
- the structured P2 finding from the earlier independent Review;
- the candidate's green verification evidence;
- bounded repository text, symbol, AST, and call-graph tools.

It did not receive the custom evaluator, later upstream fix, maintainer discussion, defect label, or
a Gold Patch. The scripted Reviewer in this run only replayed the already frozen live finding and
consumed zero new Reviewer tokens.

## Result

The Implementer used 20 tool calls and returned four structured edits. The replacement Patch:

- restores `None` as the public missing-default result;
- routes `Parameter.get_default()` and `Parameter.consume_value()` through the public overridable
  `Context.lookup_default()` method;
- adds a regression test using a custom Context subclass.

The repair was accepted after one attempt. The full suite passed **1324 tests**, with 21 skipped and
1 expected failure; the Harness-derived changed-test replay passed **10 tests**. The repair stage
took 254.8 seconds and used 215,956 input, 14,823 output, and 196,992 cached tokens.

The hidden Base/Candidate/Repaired evaluator then produced the decisive behavioral sequence:

```text
Base      -> extension point honored
Candidate -> extension point bypassed
Repaired  -> extension point honored
```

That separates requirement resolution from merely satisfying candidate-authored tests.

## Cost boundary

The original live Independent Review took 291.6 seconds and 260,892 input/output tokens. Combined
with the repair call, the observed Review-plus-repair path took 546.5 seconds and 491,671
input/output tokens, excluding cache accounting. This is a successful high-value case, not evidence
that every Patch should pay that cost. Deterministic routing and shadow measurement remain necessary.
