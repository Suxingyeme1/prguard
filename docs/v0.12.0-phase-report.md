# v0.12.0 phase report: visual terminal walkthrough

Status: implemented 2026-09-04.

## Objective

Make PRGuard understandable before a user learns its JSON artifacts or directory layout. One
command should visibly connect the Issue, frozen Git version, Implementer edit, deterministic test
failure, evidence-guided repair, final Patch, and auditable delivery.

## Implementation

`prguard demo` creates a disposable local Git repository with a faulty `clamp()` function and three
tests. It runs the production `FixRunner`, structured-edit materializer, `VerificationHarness`, and
Manifest verifier. A deterministic scripted provider replaces only the remote model call so the
walkthrough remains stable, free, and usable without credentials.

The terminal renderer has no UI-framework dependency. It detects terminal color support, retains a
plain `--no-color` mode for CI/logs, renders exact pytest argv and exit codes, extracts one useful
failed assertion, colorizes the final Git Diff, and prints direct Artifact and Manifest paths.

## Boundary

The introductory screen demonstrates test-driven Implementer repair. It does not pretend the
scripted provider measures model intelligence, and it does not simulate an Independent Reviewer.
Reviewer value remains supported by the frozen Click real-PR evidence. A later visual scenario may
render that archived Review-and-repair chain without changing its evidence.
