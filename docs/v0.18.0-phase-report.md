# v0.18.0: Repository setup, recovery and browser regression

## Delivered

- Added a collapsed repository setup guide to the welcome page and local task form. It covers
  clean Git state, separate run directories, terminal-owned credentials and execution boundaries.
  The copyable command uses explicit path placeholders; the page never runs it.
- Included an external-policy format example with warnings about adapting commands/scopes and
  missing tests. Repository-owned policy still cannot be overridden.
- Displayed actual policy provenance and original preparation warnings before approval. Automatic
  discovery is not presented as evidence of complete Issue or regression coverage.
- Added typed recovery categories for repository/path/version/policy failures, translated next
  steps and a separate raw-error disclosure. Returning to edit preserves the submitted request
  and requires fresh preparation and approval.
- Added development-only Playwright end-to-end tests with an ephemeral server and repository for
  each case. CI has a separate browser job; production Studio remains dependency-free JavaScript
  served by its existing Python adapter.

## Verification

- **325 Python tests passed** in the complete suite.
- **12 Node state/parser/localization tests passed**.
- **5 real-browser tests passed**, using the installed Google Chrome through Playwright with a
  separate temporary profile. They cover reviewed execution, keyboard navigation, exact Patch
  download SHA-256, refresh without duplicate start, history, narrow layout, language preservation,
  version-error recovery, HTML-like Issue text and no final delivery after a Reviewer outage.
- Ruff and JavaScript syntax checks passed. Browser setup adds only a separately locked test
  dependency, with no additions to PRGuard's runtime Python dependencies.

The browser download of Playwright's Chromium was slow, so local verification used the existing
Chrome channel. CI is configured to install its pinned Chromium build; this report does not claim
a completed remote CI run. The original model replies and simulated outage are deterministic
fixtures. Git, pytest, HTTP approval and download integrity checks execute for real. No paid
provider call, new upstream benchmark result or company server operation occurred.

## Remaining boundaries

The source repository is still chosen at local startup. The setup guide does not clone repositories,
write policies, install dependencies or test models. History is per process, cancellation is not
available, and standalone candidate upload is not yet a browser workflow. The browser suite is
functional Chromium coverage, not a cross-browser or accessibility certification. Error guidance
helps users decide what to fix; it cannot prove environment readiness or authorize a wider gate.
