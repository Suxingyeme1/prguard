# v0.8.2 phase report: bounded static call-graph navigation

## Outcome

Version 0.8.2 turns the existing one-hop Python caller/callee lookup into an Agent-usable impact
query. Implementer and Independent Reviewer can ask for a caller, callee, or bidirectional
neighborhood around one symbol without receiving shell access or causing repository execution.
The key-free `inspect-symbol` CLI exposes the same query at a FixTask's frozen Base Commit.

The query is deliberately small and explicit:

- the root must be an exact qualified name or one unique suffix;
- ambiguous names return candidates and no graph;
- depth is fixed to one through three;
- total returned edges use the existing 1-to-200 result bound;
- every edge carries file, line, lexical expression, and resolution evidence;
- nodes distinguish repository definitions from external or unresolved targets;
- reachable test symbols and heuristic related-test files are reported separately;
- the complete response consumes the same shared context-byte budget as every other read tool.

Package re-export resolution also now rewrites qualified member prefixes. For example, a test that
imports `PublicClass` from a package `__init__.py` and calls `PublicClass.method()` can be linked to
the defining module when the import chain is statically visible.

## Frozen real-repository check

The deterministic check reused PrettyTable at exact commit
`3c80d392d32f48b0ab1e368793ddb751dbe41807`. No repository code was imported or executed. Querying
`prettytable.prettytable.from_html` with `direction=both`, `max_depth=3`, and `max_results=80`
produced:

| Evidence | Observed value |
| --- | --- |
| Python files indexed | 15 |
| Parse errors / large-file skips / index truncation | 0 / 0 / false |
| Graph nodes / edges | 7 / 6 |
| Reachable public test symbols | 3 |
| Heuristic related test files | `tests/test_html.py` |
| Graph truncation | false |

The graph linked `from_html_one -> from_html`, the direct test call to `from_html`, two tests that
call `from_html_one`, and the downstream `_make_table_handler` dependency. Calls through the public
package re-export were labeled `import_alias_reexport`; the local helper call was labeled
`module_definition`; the instance call `parser.feed` remained explicitly `unresolved_lexical`.

The path-free [public evidence package](../evidence/call-graph-hardening/README.md) stores the frozen
query summary and SHA-256 hashes.

## Claim boundary

This proves that the deterministic tool can expose a useful bounded static neighborhood on one real
repository. It is not a new live-model success, does not prove that a model will always choose the
tool correctly, and is not a runtime-complete call graph. Dynamic dispatch, reflection, dependency
injection, monkey-patching, generated code, and missing source remain outside the result. The Agent
must still read cited lines and the deterministic Harness must still run the declared verification
gate.

## Next priority

Use the new impact evidence as one input to deterministic Reviewer routing: central symbols,
security-sensitive paths, weak test reachability, or a prior repair can justify independent review,
while narrow well-tested edits can avoid its latency and Token cost. Routing policy must be tested
against the existing true-positive and false-block evidence before becoming an accepting gate.
